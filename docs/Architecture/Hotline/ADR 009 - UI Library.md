## Objetivo
#### Definir a UI Library utilizada para o FrontEnd

#### Finalizado em 03 fev 2026

### Library
Definir qual UI library utilizar no Frontend, considerando sua continuidade, estabilidade, estilo e custos

#### Resultado:
- Google Material

##### Prós
- Library padrão do Angular, mantido pela google
- Bem conhecido no mercado
- Comunidade grande e ativa
- Estável
- Acompanha todas as versões do angular
- Ganhou notoria performance nas ultimas versões
- Possui themes ja definidos bem utilizaveis
- Permite componentização
- Permite customização
- Open source / free


##### Cons
- Não é a Library com maior numero de componentes prontos
- Algumas customizações podem exigir maior trabalho
- Em alguns casos excepcionais, a performance pode degradar
