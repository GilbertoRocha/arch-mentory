## Objetivo:

### Mentoria em arquitetura de sistemas, objetivando em buscar a reciclagem de conhecimento, para focar em sistemas distribuidos usando microservicos.

A ideia é através de um projeto ficticio, exercitar as escolhas relacionadas a arquitetura, aonde o projeto irá iniciar pequeno, mas será "expandido", objetivando um sistema complexo, organizado por DDD e usando as tecnicas arquiteturais modernas condizentes.

O foco **não** é o desenvolvimento do sistema em si, mas todo o processo criativo para projeta-lo, aonde as decisões arquiteturais ( *ADR* ) precisam estar presentes e embasadas. O sistema em si será desenvolvido apenas o minimo necessário para experimentação e para cumprimento das decisões arquiteturais.
